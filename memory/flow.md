# Поток решений

- Память проекта включена: папка mem0-like\memory\ с файлами по темам + поиск mem0-like\search.py (SQLite FTS5 + multilingual MiniLM-L12-v2), запуск: mem0-like\.venv\Scripts\python.exe mem0-like\search.py "запрос" -k 5.
- Проектные инструкции лежат в AGENTS.md в корне workspace: описывают память, команду поиска, когда искать и когда писать. Новые сессии в этом workspace загружают их автоматически.
- Git-репозиторий памяти — в папке mem0-like\. Под контролем: .gitignore, memory\*.md, memory.md (указатель), search.py, init.py, README.md, agents-example.md. Не трекются: .venv\, .models\, memory.db (скачанное и производное).
- Копия проектных инструкций для git — mem0-like\agents-example.md; рабочий файл — AGENTS.md в корне workspace (его загружает приложение). Правки синхронизировать копированием, проверка — Get-FileHash на обоих.
- Копия названа agents-example.md, а не agents.md: Windows не различает регистр, и приложение прочитало бы mem0-like\agents.md как mem0-like\AGENTS.md — инструкции инжектировались бы дважды. После переименования двойная загрузка снята.
- Инициализация после клонирования — python mem0-like\init.py: собирает .venv (python -m venv), ставит fastembed (pip, кэш .pip-cache затем удалён), скачивает модель в .models и перестраивает memory.db из memory.md. Флаги: --check (диагностика без правок и без сети), --force (перекачать модель и перестроить индекс). Код выхода 0/1.
- Проверено: пустый .models → init.py скачивает модель, эмбеддинги работают (размер вектора 384); удалённый memory.db → индекс перестроен (60 документов); повреждённый config.json → FAIL «модель не загружается», лечится --force.
- Проект называется mem0-like: папка переименована из память\ в mem0-like\, git-репозиторий перенесён вместе с .git\. Пути обновлены в AGENTS.md, README.md, memory.md, agents-example.md, init.py, search.py; код путей в скриптах относительный (от самого файла), поэтому переименование папки их не ломает.
- Старая пустая папка память\ не удаляется: её держит открытый handle процесса приложения. Содержимое уже перенесено, в старой папке файлов нет; удалится после перезапуска приложения.
- Сеть: за арендованным ZTE провайдера с изоляцией клиентов (устройства в его LAN не видят друг друга) ставится второй интернет-центр Netcraze Starter NC-1121 (он же Keenetic Starter KN-1121) — кабель провайдера в его WAN-порт, своя подсеть за NAT, устройства за Netcraze видят друг друга
- NC-1121: 3 порта Ethernet 100 Мбит/с, маршрутизация IPoE/PPPoE до ~95 Мбит/с, Wi-Fi только 2.4 ГГц N300 (2T×2R, 40 МГц, 300 Мбит/с теория) → для ноды с AX210 против решения #31 (5 ГГц, 80 МГц), реально ~30–60 Мбит/с как в #30
- Регулирование оборотов не завязано на BIOS (плата ещё не куплена, зайти в BIOS нельзя): базовая схема — NF-A12x25 на постоянных 12 V, его максимум 1500 об/мин уже рабочая точка (#25, ~19–20 dBA); BIOS DC-режим только бонус для тишины в простое (пороги 55 / 65 / 70 °C из #28, DC ниже 1500 об/мин)
- Перевод оборотов в напряжение для DC: NF-A9x14 (макс 2200) — 1300 об/мин ≈ 60 % (~8.5 V), 1800 ≈ 80 % (~10.5 V), 2200 = 100 %; NF-A12x25 (макс 1500) — 1300 об/мин ≈ 75 % (~9.5 V), 1500 = 100 %, выше 1500 BIOS не поднимет, пик 120 Вт держит только NF-A9x14 на 2200
- Если DC-режима в BIOS нет: 4-pin без управления = вентилятор на 100 % постоянно (NF-A9x14 2200 об/мин, ~22 dBA), тогда LNA 700–1000 ₽ или ручной DC-регулятор 600–900 ₽ или автоконтроллер с датчиком 1500–2500 ₽; нижняя граница DC не ниже 7–8 V
- Проверка fan-control до покупки платы (BIOS недоступен): по фото карточки считать контакты fan-header (3 vs 4), искать скриншот BIOS с Hardware Monitor / Smart Fan и режимом DC (Voltage), спросить продавца close-up header'а; там же проверять through-hole vs near-hole вокруг сокета (#76) и позицию VRM (#48)
- Если BIOS без DC и тишина нужна: регулятор питается от Molex БП и не зависит от платы — ручной DC 600–900 ₽ или автоконтроллер с датчиком 1500–2500 ₽; PWM-вентилятор Noctua совместим с DC до 7–8 V (#41), поэтому 3-pin header не мешает
- GPU Gigabyte GV-N506TWF2OC-16GD (RTX 5060 Ti 16 GB): интерфейс PCIe 5.0 ×8, TGP 180 Вт, питание 1× 8-pin (подтверждено таблицей десктопных RTX 50 на en.wikipedia.org, со ссылкой на TechPowerUp c4246; карточка Gigabyte не открылась — Akamai 403). В слоте PCIe x16 на X79/C602 (#3) карта встанет физически, но линия остаётся ×8: на v2-процессоре это PCIe 2.0 ×8 ≈ 4 ГБ/с, на v3 — PCIe 3.0 ×8 ≈ 8 ГБ/с.
