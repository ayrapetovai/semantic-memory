# semantic-memory

## Поток решений

- Доступен MCP-сервер semantic-memory: индекс проекта содержит 16 фактов, 11 файлов, 91 символ, 1513 вызовов, язык C, embeddings включены; инструменты вызываются через execute как tools['semantic-memory'].* (index_stats, file_outline, references, callers, callees).
- Пользователь называет MCP-плагин semantic-memory словом «memory»: фразы вроде «check memory» означают обращение к этому плагину (index_stats, references, callers, file_outline).
