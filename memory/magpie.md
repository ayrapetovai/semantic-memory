# magpie

## Decision stream

- the_patch.patch had recipe lines indented with 7 spaces instead of tabs; `git apply --ignore-space-change --check` passes but makes no changes (--check is dry-run), plain `git apply` fails at Makefile:17. After applying with --ignore-space-change, `make` failed with 'missing separator' at Makefile:14 (main.o recipe) and at clean: recipe — fix by converting those leading spaces to tabs. `make` then built magpie successfully; linker warns sset.o requires executable stack.
- magpie purpose/CLI (main.c): generates random English phrases from a weighted context-free grammar. Commands implemented: `magpie say` (phrase), `magpie say-grammar` (list of grammar-node names), `magpie grammar` (print the whole grammar); no arguments prints 'no arguments provided.'; unknown command exits 2. RNG seeded from CLOCK_MONOTONIC nanoseconds. README describes a much broader CLI (args like greeting addressing:John, repeat, syntax only, --nouns=...) that is NOT implemented yet.
- magpie grammar model (main.c): static graph of `Grammar` nodes rooted at `phrase`, node types PUNCT/PROD/TERM, up to MAX_PRODUCTIONS=20 weighted `Production`s each with an int `probability` and up to MAX_TERMS_IN_PRODUCTION=20 child pointers. `generate_phrase_grammar()` picks a production by cumulative weight (`rand() % total_probability`) and recurses; leaves are pushed into an aqueue. `print_all_grammar()` walks the same graph breadth-first with an sset for dedup to implement the `grammar` command.
- magpie text generation: `generate_phrase()` drains the leaf queue into a string queue — TERM nodes call their `text()` function pointer (declared via the TERM_RULE macro), PUNCT nodes emit literal '.', '!', '?', ',', and spaces are inserted between words. `say()` uppercases the first character, concatenates via `str_append`, prints; sample output: 'What do remarkable bottle swing peeping?'.
- magpie word data/build: words live one-per-line in res/*.txt (nouns 1736, verbs 1043, adverbs 331, adjectives 150, numerals 15; also conjunctions, pronouns, prepositions, linking/frequency/conjunctive adverbs that main.c does not include). `mk_imbedable_header.c` converts each list into gen/<name>.h with `const char* <name>[]` and `<name>_size`; the Makefile target `generate_headers` (phony) regenerates all 9 headers using `$(ls ./res)`; main.c includes gen/nouns.h, verbs.h, adverbs.h, adjectives.h, numerals.h and picks with `abs(rand()) % size`; plurals are naive +s, gerunds verb+ing. No tense/voice/person/addressability context is implemented despite the README design.
- magpie support libraries: `aqueue.c` = circular array FIFO of void* with doubling on full, poll/offer, `aqueue_to_string` with a mapper; `sset.c` = string hash set (chaining, power-of-2 buckets, initial 16, load factor 0.75, hash 31*n+c with xor-shift, grows by rehash) used for dedup in grammar printing; `str.c` = char buffer with a flexible array, length/capacity, `str_from_chars`, `str_append` (realloc by malloc+copy), `str_free`. Each has a small standalone test .c (sset_test, aqueue_test, str_test).
- magpie build/test: Makefile `all: test magpie`; CFLAGS = -O2 -std=c11 -D_POSIX_C_SOURCE=200809L; `make` builds magpie plus three test binaries and appends all test output to a file named `test`; `make clean` removes binaries, objs and gen/*; root main.o depends on the phony `generate_headers` so headers regenerate on every build. Note: `HEADER_SOURCES=$(ls ./res)` and the unused `ALL_SRC = $(pattern *.c)` (invalid make function) are fragile leftovers. Link emits a warning that sset.o requires an executable stack.
- Magpie generates random English phrases from a weighted context-free grammar; only the commands `say`, `say-grammar`, `grammar` are implemented, the rest of the README CLI (repeat, --nouns=..., syntax-only) is not implemented; the RNG is seeded from CLOCK_MONOTONIC
- Grammar in main.c: a static graph rooted at `phrase`, node types PUNCT/PROD/TERM, up to 20 weighted productions, selection by cumulative probability, leaves collected into an aqueue; TERM generators are declared with the TERM_RULE macro
- Words come from res/*.txt and are turned by mk_imbedable_header.c into gen/*.h (`const char* name[]`, `name_size`); number/gender/tense are not taken into account, plural = +s, gerund = +ing; Makefile: CFLAGS=-O2 -std=c11 -D_POSIX_C_SOURCE=200809L, make builds magpie and 3 test binaries, `ALL_SRC = $(pattern *.c)` — unused garbage
